# Intentional UX

Intentional UX is a public plugin foundation for guidance on deliberate, human-centered product and interface decisions.

## Discovery

The plugin identifier is `intentional-ux` and its version is `0.1.0`.

- Codex discovers the plugin through `.codex-plugin/plugin.json` and its `./skills/` declaration.
- Claude discovers the plugin through `.claude-plugin/plugin.json`; `.claude-plugin/marketplace.json` provides a repository-local marketplace entry.

The substantive skill content will be added in a later change.
